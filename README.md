# 🎮 Chainsaw Man  
### 🩸 *A 3D First-Person Horror Experience*

---

## 📌 **Overview**

**Chainsaw Man** is a first-person psychological horror game developed using **Unity**.  
The game immerses players in a dark, atmospheric world where fear is built through **sound, lighting, and exploration**.

Designed as a showcase of **environmental storytelling and immersive design**, this project focuses on subtle tension rather than direct action.

---

## 🎯 **Gameplay Overview**

- 🕯️ **Explore** a haunted environment filled with hidden story elements  
- 👁️ **Experience** slow, suspense-driven gameplay  
- 🧩 **Interact** with objects and uncover environmental clues  
- 🔊 **Dynamic audio and visuals** react to player movement  

---

## ✨ **Core Features**

- 🎥 **First-Person Controller**  
  Smooth and immersive player movement  

- 🌫️ **Atmospheric Visual Design**  
  Realistic lighting, fog, and post-processing effects  

- ⚡ **Interactive Event System**  
  Trigger-based environmental changes and scare events  

- 🎧 **Advanced Sound Design**  
  Spatial audio for deep immersion  

- 🧠 **Efficient Game Logic**  
  Modular scripting using **C#**  

---

## 🛠️ **Tech Stack**

- 🧩 **Engine:** **Unity**

---

## ⚙️ **Setup Guide**

Get started instantly — no setup required.

1. 📥 **Clone or download** the repository  
2. 📁 **Open** the project folder  
3. ▶️ **Navigate** to the **Build** directory  
4. 🚀 **Double-click** **Chainsaw Man.exe**  

> 💡 **Note:** Unity is **not required** to play the game.

---

## 🎮 **Controls**

- ⌨️ **W / A / S / D** → Move  
- 🖱️ **Mouse** → Look around  
- 🔘 **E** → Interact
